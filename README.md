# SID Player for OpenCloud - demo site

This branch is the demo published with GitHub Pages: the SID Library as it
looks in OpenCloud, with ten tunes and no server. The app itself is on the
`main` branch.

`_demo/` is the source of the site; everything else here is its build, made by

```
_demo/build.sh
```

which takes the app from `main` and the tunes from `demo`, and replaces the
previous build at the root of this branch.
